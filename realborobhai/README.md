# Real Boro Bhai — যেভাবে পোস্ট দেবেন

প্রতিটি পোস্টের জন্য `inbox` ফোল্ডারের ভেতরে একটি নতুন ফোল্ডার খুলুন।

**ফোল্ডারের নাম:** `তারিখ_দোকানের-নাম`, যেমন `2026-10-16_sultans-dine`

**ফোল্ডারের ভেতরে রাখবেন:**
1. খাবারের ১টি থেকে ১০টি ছবি (jpg/png)
2. `post.txt`: `_TEMPLATE/post.txt` কপি করে পূরণ করুন

**GitHub-এ আপলোড করার ধাপ:**
1. github.com/hmtkamrul/top10-media খুলুন → `realborobhai` → `inbox`
2. **Add file → Upload files**
3. ছবিগুলো আর পূরণ করা `post.txt` টেনে এনে ছেড়ে দিন
4. ওপরে ফোল্ডারের নামের জায়গায় লিখুন, যেমন `2026-10-16_sultans-dine/`
5. **Commit changes** চাপুন

এরপর নির্ধারিত দিনে ও সময়ে Claude নিজেই ক্যাপশন লিখে পোস্ট করবে, আর পোস্ট হয়ে গেলে ফোল্ডারটি `posted`-এ সরিয়ে রাখবে।
